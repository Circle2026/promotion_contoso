# promotion_contoso
# 消費行為與促銷策略分析

> 從顧客、產品與季節性數據，分析如何在提升銷售的同時維持獲利。

## 專題簡介

本專題以 Contoso Corporation 模擬零售資料為分析對象，探討促銷折扣、產品類別、銷售通路與消費行為之間的關聯，並評估不同促銷策略對營收與毛利表現的影響。

分析目的不是單純追求銷售成長，而是找出更適合不同產品與通路的促銷方式，作為企業制定折扣及營運策略的數據參考。

## 分析重點

- **折扣與毛利的關係**：觀察折扣幅度增加時，毛利率如何變化，並辨識可能侵蝕利潤的區域。
- **產品類別差異**：比較不同品類的毛利表現與折扣敏感度，找出適合促銷與需要控管折扣的產品。
- **銷售通路差異**：檢視不同電商平台的銷售情形，評估通路客群差異對促銷效果的影響。
- **折扣與銷售量、營收的關聯**：比較不同折扣區間的營收與銷售量，觀察促銷是否帶來相應的銷售效益。
- **季節性促銷機會**：結合季節與促銷情境，思考如何安排活動以兼顧銷售成長與獲利。

## 初步觀察與商業洞察

- 整體平均毛利率約 **55.89%**，高於本分析採用的 **35%** 參考基準；平均折扣率約 **5.92%**。
- 折扣並不必然造成整體毛利下滑，但影響會因產品類別與銷售通路而異。
- **Music, Movies and Audio Books** 類別毛利率約 **58.65%**，呈現較高的毛利表現。
- **Download Games** 與 **Computers** 在較高折扣區間的毛利較弱，顯示高折扣可能進一步壓縮原本較薄的利潤。
- 相同產品在不同通路的銷售情形可能不同，因此促銷策略宜依產品與通路分層規劃。

> 以上為資料中的觀察結果與關聯分析，不代表折扣是造成銷售或毛利變化的唯一原因。

## 初步策略建議

1. 對毛利較穩健的產品，評估以適度促銷帶動銷售。
2. 對毛利較薄的產品，避免單純加深折扣，可搭配配件、組合方案或其他加值活動。
3. 依平台客群與產品類別設計差異化促銷，而非採用單一折扣方案。
4. 持續追蹤折扣區間的營收、銷售量與毛利率，確認促銷帶來的效益是否足以抵銷利潤減少。

## 分析流程

1. 確認資料欄位與分析範圍。
2. 依產品類別、銷售通路及折扣區間整理資料。
3. 比較營收、銷售量與毛利率等指標。
4. 透過儀表板探索各分群的差異與關聯。
5. 彙整洞察並提出可供業務評估的促銷建議。

## 專題範圍與限制

本專題以 Contoso Corporation 模擬資料進行探索性分析。分析結果適合作為策略討論與後續驗證的起點；實際促銷決策仍應搭配成本、庫存、活動期間及顧客分群等資訊評估。
